# 永續連結貸款 KPI 履約監測

需要 Python 3.10 以上與一般瀏覽器，免安裝第三方套件。先解壓縮整個 ZIP。

- Windows 可雙擊 `start-windows.bat`。
- macOS 可開啟 `start-mac.command`。若系統未允許直接開啟，在「終端機」進入專案資料夾後執行 `sh start-mac.command`。
- 也可直接在專案資料夾執行 `python app.py`。Windows 可改用 `py app.py`，macOS 可改用 `python3 app.py`。

程式會嘗試開啟瀏覽器。若未自動開啟，複製終端機列出的網址，通常為 http://127.0.0.1:8765 。預設連接埠被占用時，請使用程式列出的替代網址。以 Ctrl+C 結束服務。

## 老師驗收

1. 選「正常達標」，點「執行履約評估」。預期減幅 11%、達標、利差調整 −5 bps。
2. 在結果頁輸入覆核日期 2026-06-15 並選「確認試算」。預期生效日為 2026-07-01。展開原文證據或匯出 CSV。
3. 選「缺查證」或「併購與重編」，再執行評估。預期顯示待人工覆核及原因。可填備註退回補件，再修正並重跑。
4. 從「履約紀錄」或「上一版本」回到各版本。SQLite 紀錄預設儲存在同目錄的 history.sqlite3。

內建案例與模擬擷取可離線使用。自訂輸入可貼上或匯入 UTF-8 TXT，每份最多 12 KB，格式參考預填內容。建議先核對預覽，再按下評估，證據以文件名稱及行號呈現。各案的評估年度與版本列於履約紀錄。這版以單年度提交驗證，完整的同借款戶跨年度彙總尚待實作。

## 實際模型

在啟動前於本機環境設定 GEMINI_API_KEY。GEMINI_MODEL 預設 gemini-3.5-flash-lite。若未設定 Gemini 金鑰，也可設定 OPENAI_API_KEY（或 LLM_API_KEY），OpenAI 模型由 SLL_MODEL（或 LLM_MODEL）指定。選擇「實際模型」後執行，資料會傳送至畫面標示的模型服務，請使用教學合成資料。服務錯誤會明確顯示，介面可切回模擬模式。實際模型的輸出品質與課程至少 20 個獨立案例的整體驗收待驗證。

此原型支援範疇一與二排放量減幅、合約所列達標及未達標基點、覆核通過次月首日生效。支持的排放量單位為 tCO₂e。正式利率調整由授權人員作業。

## 重跑驗收

在解壓縮後的 `sll` 資料夾執行 `python verify.py`。Windows 可用 `py verify.py`，macOS 可用 `python3 verify.py`。此步驟免金鑰、免啟動網站，會重建驗收報告及明細。教師可直接閱讀交付的 `驗收報告.md`。

- `samples_dev.json` 與 `samples_test.json` 分別保存 5 個開發及 20 個獨立驗收案件。各含同一借款戶 2024、2025 的合成盤查文件與對應年度合約條款。2025 為正式測試年度，2024 提供配套回歸驗證，各年度可分開匯入。
- `python generate_samples.py` 以 seed=42 重建資料。種子決定基準排放量，各情境以預先指定的排放比例、門檻與人工設定的應有結果建立。欄位與原文位置由資料生成器按行索引建立標準答案。樣本限定教學格式，未涵蓋真實企業文件的多版式及查證品質。
- 實際模型另用 `python verify.py --live` 產生獨立報告。先在系統環境設定金鑰，變數名稱見 `.env.example`。此指令會向已設定的模型服務發送每筆可讀取的合成案例。交付的報告未執行此模式。

## Vercel 線上驗收

開啟 [Vercel 教學展示版](https://sll-kpi-monitor-poc.vercel.app)。老師可以從同一頁使用內建案例或匯入教學 TXT，檢視證據、人工確認或退回補件，再下載 CSV。

- 預設 `[MOCK MODE]` 免登入、免金鑰。線上版本用私有 Vercel Blob 保存覆核版本，以該瀏覽器的 Cookie 識別。同一瀏覽器可查閱版本。清除 Cookie 或換瀏覽器後，需重新建立案件。本機版繼續使用 SQLite。
- 要開啟實際模型，請在 Vercel 專案的 Production 環境加入 `GEMINI_API_KEY` 與 `SLL_TRIAL_CODE`，再重新部署。可另設 `GEMINI_MODEL`。Gemini 金鑰設定後，真實模式只向 Gemini 送出請求。Gemini 使用 Google 提供的相容端點以 JSON 格式擷取資料；每次評估提交一次生成請求。結果和 CSV 標示實際使用的模型。老師選「實際模型」並輸入試用碼後，即可分析。每次按下執行才發出模型請求。
- 真實模型請使用教學合成資料。金鑰與試用碼設在 Vercel 後端環境變數。覆核與下載不呼叫模型，正式利率調整由銀行授權人員確認。

## 任務四真實 Gemini 驗收

本機設定 `GEMINI_API_KEY` 後執行 `python smoke_gemini.py`，只會送一筆內建合成案件。此檢查驗證欄位值、原文行號、履約試算及人工覆核後的生效日。實測證據見 [任務四真實 Gemini 驗收紀錄](任務四_Gemini實測.md)。

首頁的示範案件下拉選單會帶入兩份教學文件。選「生成隨機文件」可取得一組新的合成資料，填入表單並下載為兩份 UTF-8 TXT。網站的「使用說明」包含正常評估、缺件補件、Gemini 模式及 CSV 匯出的操作步驟。

使用未改動的內建文件評估後，可在結果頁核對「內建案例驗收」。有上一版本的案件可查看「補件前後比較」。在「使用說明」點「一鍵跑 20 案模擬驗收」，可重跑獨立測試集並查看基準比較和失敗案例。批次驗收不呼叫 Gemini，也不新增履約紀錄。
